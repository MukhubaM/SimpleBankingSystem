# Simple Banking System

##  Overview
The **Simple Banking System** is a Java-based application that simulates basic banking operations.  
It provides a foundation for understanding object-oriented programming concepts, file handling and user interaction in Java.

---

##  Features
- **Create Account** – Register new customers with account details.  
- **Deposit Funds** – Add money to an account.  
- **Withdraw Funds** – Withdraw money with balance validation.  
- **Check Balance** – Display the current balance of an account.  
- **Persistent Storage** – Save and load customer data using serialization.  

---

##  Tech Stack
- **Java (JDK 17+)**
- **Object-Oriented Programming**
- **File Serialization** for persistent storage
- **Console-based UI** (can be extended to GUI)

---

##  Project Structure
- `Customer.java` → Model class representing a bank customer.  
- `BankingSystem.java` → Core banking operations (deposit, withdraw, balance check).  
- `BankingApp.java` → Main entry point to run the application.  
- `BankAccount/` → Serialized file storage for customer accounts.
